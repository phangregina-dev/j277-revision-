# OCR GCSE Computer Science (J277) Revision Hub

A free, single-page revision site for **OCR GCSE Computer Science J277**, organised by the official specification headings (spec v3.1).

## What's inside

| Feature | Details |
|---|---|
| Topic explorer | 8 topics with notes, filterable by paper |
| Practice quiz | 75 exam-style questions, filter by topic and Foundation/Higher; missed questions are listed at the end with explanations |
| Flashcards | 75 terms with flip animation, shuffle and topic filter (keyboard: Enter/Space to flip, arrows to move) |
| Cheat sheet | OCR reference-language syntax, formulae and quick facts |
| Algorithm visualiser | Animated bubble, merge and insertion sort, plus linear and binary search |
| Exam tips | 12 strategy tips |

## Topics covered

**Paper 2 — Computational thinking, algorithms and programming (J277/02)**

- 2.1 Algorithms
- 2.2 Programming fundamentals
- 2.3 Producing robust programs
- 2.4 Boolean logic
- 2.5 Programming languages and IDEs

**Paper 1 — Computer systems (J277/01)** (selected topics)

- 1.2 Memory and storage, including data representation
- 1.3–1.4 Networks, connections, protocols and network security
- 1.6 Ethical, legal, cultural and environmental impacts

Paper 1 topics 1.1 (systems architecture) and 1.5 (systems software) are not covered yet.

## Run it

Open `index.html` in a browser, or publish with GitHub Pages (set the source to the `main` branch, root folder). No build step and no dependencies.

## Note

This is an independent revision aid and is not affiliated with or endorsed by OCR. Always check the official specification and past papers.
